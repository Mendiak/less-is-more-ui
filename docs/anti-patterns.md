# UI Anti Patterns

Avoid the following patterns unless absolutely necessary.

## Excessive decoration

Avoid:

- heavy gradients
- excessive shadows
- glassmorphism
- neumorphism

---

## Visual clutter

Avoid:

- too many cards
- **Decorative icons:** Adding icons just to "fill" space or make it look "modern".
- **Redundant icons:** Using an icon when the text is already clear (e.g., an icon of a home next to the word "Home" in a simple navbar).
- multiple accent colors
- decorative elements without purpose

---

## Overcomplicated layouts

Avoid:

- deeply nested containers
- crowded dashboards
- too many UI sections

Prefer calm and simple layouts.
