## The short version

Remove what does not serve the task. Let typography, alignment and whitespace carry the structure. Use one grid, one spacing scale and one accent colour.

Every rule in the following pages is a consequence of that sentence. When two options are equally functional, choose the one that adds less.

## How to use this documentation

Read the principles before the components. Components copied without the axioms reproduce the appearance of restraint without its logic, and the result collapses as soon as a new screen has to be designed.

If you are an AI agent, `llms.txt` lists this documentation in a compact form, and `llms-full.txt` contains the same text in plain Markdown for ingestion.
