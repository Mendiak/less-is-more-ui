Less Is More UI exists because most generated interfaces look the same: rounded cards, soft shadows, gradients, and a hierarchy built entirely from containers. That look is not wrong because it is fashionable. It is wrong because it asks the user to decode packaging before reaching content.

## The premise

This project starts from the modernist claim that structure and typography can carry an interface on their own. If that is true, most decoration is not just unnecessary — it is a cost. Every shadow, border and badge is something the user has to read past.

The system turns that claim into rules that an AI agent can follow and that a person can verify. The rules are in the [documentation](/less-is-more-ui/docs/); the showcase applies them to real interface patterns.

## How it is maintained

The project is deliberately small. Changes are made when a real interface exposes a gap in the rules, not to add features. Every release is recorded in the [changelog](/less-is-more-ui/changelog/).

Contributions are welcome: issues with a concrete screen and a concrete problem are more useful than abstract suggestions.

## Design credits

The principles referenced throughout the site come from Ludwig Mies van der Rohe, Louis Sullivan, Dieter Rams, Jony Ive, Josef Müller-Brockmann and Massimo Vignelli. The mistakes in applying them are the author's.
